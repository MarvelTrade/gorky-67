# Выкладка в Яндекс Игры — чек-лист

Сборка: `npm run build:yandex` → `build/gorky-67-yandex.zip` (SDK подключён, бота и кнопки статистики нет,
уровни открываются по очереди). Для тестеров по ссылке — `npm run deploy` (без SDK, все уровни открыты).

## Техника — сделано
- [x] index.html в корне архива, латинские имена, размер ~2 МБ (лимит 100 МБ)
- [x] SDK из `/sdk.js`, без SDK — заглушки, игра не падает
- [x] `LoadingAPI.ready` — когда на экране меню
- [x] `GameplayAPI start/stop` — забег, выбор улучшения, пауза, смерть
- [x] Реклама только через SDK: межстраничная между забегами (не чаще интервала), за вознаграждение — «Воскреснуть»
- [x] Звук выключается при рекламе, паузе платформы и уходе со вкладки
- [x] Сохранения в облаке игрока (рекорд, «Ангар», настройки, открытые уровни), копия в localStorage
- [x] Язык из SDK (ru/en), тексты полностью на обоих языках
- [x] Нет выделения текста, прокрутки, масштабирования жестами и контекстного меню по долгому нажатию
- [x] Нет внешних ссылок и инструментов разработчика (FPS, бот, «скопировать статистику» — только в dev)
- [x] Телефон стоя и лёжа, планшет стоя и лёжа: меню, карта, «Ангар», итоги, пауза, HUD

## Содержание — проверить автору
- [ ] Возрастной рейтинг: стрельба по заражённым, ядерный удар → вероятно 12+ или 16+
- [ ] Политика: модерация не пропускает политическую агитацию. У нас выдуманные республика и город, без
      реальных лиц и событий. Рискованные места: лагерь «Зона» с вышками в Горьком-67, «чинуши»,
      ядерный удар по своим. Если модерация вернёт — смягчать подписи, не механику.
