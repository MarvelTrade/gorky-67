# Прогон бота по уровням

Цель — убедиться, что каждый готовый уровень проходится «думающим» ботом и ничего не падает.
Ориентир баланса: бот выигрывает каждый уровень, HP в конце — не у нуля и не полное.
Карьер (уровень 3) задуман самым тяжёлым.

## 1. Сборка с ботом

```bash
npm run build:bot
```

Собирает `dist-dev/` — production-сборку с инструментами разработки (`__game`, `__startBot`, `__botLevel`).
Мерить только на ней: на dev-сервере (5173) замеры хуже и непоказательны.

## 2. Сервер и чистое сохранение

- `preview_start` с именем **bot** (порт 4180). Уже запущен — перезапусти страницу после сборки.
  `preview_start` читает `.claude/launch.json` той папки, где идёт сессия. Если сессия не в папке проекта
  и «bot» там не найден — добавь туда такую же конфигурацию с абсолютными путями:
  `node <проект>/node_modules/vite/bin/vite.js preview --outDir <проект>/dist-dev --port 4180 --strictPort`.
- Сохранение должно быть пустым, иначе бот играет с купленными в «Ангаре» улучшениями:

```js
localStorage.clear(); setTimeout(() => location.reload(), 50); 'ok'
```

Перезагрузка обрывает вызов — это нормально. Следующим вызовом дождись загрузки:

```js
await new Promise(r => setTimeout(r, 1500)); for (let i = 0; i < 20 && !window.__botLevel; i++) await new Promise(r => setTimeout(r, 500)); typeof __botLevel
```

Пауза в начале обязательна: без неё проверка успевает пройти на старой странице до перезагрузки,
и следующий вызов `__botLevel` обрывается. Если обрывается сам этот вызов («page navigated») — это
перезагрузка его догнала; страница уже новая, можно сразу начинать уровень.

Бот рекламу не смотрит: сбили — сам жмёт «Завершить», забег засчитан как гибель (`win: false`, `cause`).

## 3. Уровни — по одному

Уровни берутся из `LEVELS` в `src/levels.js` (готовые — `isBuilt(n)`). Сейчас готовы 1–3.

Начать уровень (первые 120 с игрового времени):

```js
__botLevel(1)
```

Или сразу два куска одним вызовом (240 с — укладывается во время инструмента):
`let r = __botLevel(1); r.done ? r : __botLevel()`.

Пока в ответе `done: false` — продолжать тем же вызовом без номера:

```js
__botLevel()
```

Один вызов — один кусок. Не запускай несколько уровней в одном вызове: инструмент браузера
обрывает долгий скрипт («Internal error»), и результат пропадает. Если оборвалось — посмотри,
какой уровень идёт (`__game.scene.getScene('GameScene').levelDef.n`), доведи его `__botLevel()`
и перезапусти пропавший.

Каждый следующий уровень — с чистым сохранением (шаг 2): деньги с прошлого уровня копятся.

## 4. Отчёт

Таблица по уровням из итогового ответа `__botLevel`:

| Уровень | Победа | Время | HP в конце | Уровень вертолёта | Причина гибели |

Плюс что заметил: уровень слишком лёгкий (HP полное) или тяжёлый (гибель, HP у нуля), ошибки в
консоли (`read_console_messages` с `onlyErrors`). Если правил баланс — до и после.

## Подводные камни

- Панель браузера, когда скрыта, даёт 2 кадра в секунду: скриншоты отстают, твины и таймеры еле идут.
  Бот шагает игру сам (`__botRun`), ему это не мешает. Для экранов без бота шагай вручную:
  `for (...) { await new Promise(r => setTimeout(r, 20)); __game.step(performance.now(), 20) }`.
- `__game` и бот есть только в сборках с `import.meta.env.DEV` — в `npm run build` и в архиве для Яндекса их нет.
