# Обновление тестовой ссылки

Ссылка: https://claude.ai/artifact/7CeMrWegRf87PySJyburFP — приватная, открывает только автор.
По ней автор проверяет игру на телефоне. Это не публичная ссылка для тестеров:
та — GitHub Pages (`npm run deploy`), её запускает только автор.

## 1. Сборка

Сначала закоммить и запушь изменения — ссылка должна соответствовать коммиту.

```bash
npm run build
find dist -type f | sed 's#^dist/##' | sort
```

`dist/` — обычная сборка: без бота, без SDK Яндекса. JS лежит в `assets/index-<хеш>.js`,
хеш меняется с каждой сборкой.

## 2. Что лежит в артефакте сейчас

`Artifact` с `action: "list"`, `scope: "files"`, `url` — ссылкой выше. Это список опубликованных путей.

## 3. Публикация

`Artifact` (publish) с:

- `url` — ссылка выше (иначе получится новый артефакт с новой ссылкой);
- `file_path` — `dist/index.html` (абсолютный путь);
- `files` — **все** остальные файлы из `dist/` (`"assets/index-<новый>.js"`, `"sprites/…"`) с абсолютными
  путями-источниками, плюс `null` для каждого пути из шага 2, которого больше нет в `dist/` —
  обычно это старый `assets/index-<старый>.js`.

Спрайты публикуются каждый раз: если их перерендерили, иначе на ссылке останутся старые.
Без `null` старый JS (1,7 МБ) останется в артефакте мёртвым грузом.

`icon` не передавать — у артефакта он уже есть.

## 4. Проверка

Номер версии в ответе вырос. Скажи автору номер версии и что изменилось; ссылка та же.
