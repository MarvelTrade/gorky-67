# Предрелизная проверка

Правила модерации — `docs/story.md`, раздел «Чего нельзя». Чек-лист релиза — `docs/yandex-release.md`.

## 1. Автоматическая часть

```bash
npm run check:release
```

Скрипт `scripts/check-release.mjs`:

- **[!] ошибки** (код выхода 1): ключи в `ru.js` и `en.js` не совпадают; код зовёт `t('…')` без ключа;
  архив для Яндекса не собрался; в архиве есть `__game` или бот; в архиве не подключается SDK (`/sdk.js`).
- **[?] на проверку глазами:**
  - неиспользуемые ключи (собранные шаблоном `` t(`enemy_${type}`) `` и `` t(`${key}_${id}`) `` скрипт понимает);
  - запретные слова в текстах: незавершённость («не готово», «скоро будет»), война и ядерное, лагерь и власть,
    религия, Красный Крест, «любовница»;
  - надписи прямо в коде мимо `t()`: в другой версии языка останутся непереведёнными.

Быстро, без сборки архива: `npm run check:release -- --no-build`.

Каждое `[?]` разбери: исправь или объясни автору, почему так и надо. Известное и оставленное:
- `cher_end`, `l2_cher_end`, `l3_cher_end` — реплики Черёмухи «запомните…». С итогов их убрал обмен про премию; оставлены на будущее.

Слово само по себе ещё не нарушение: «удар» по району допустим, «ядерный удар» — нет.
Смысл решает человек. Сомнительное по сюжету — к агенту `screenwriter`.

## 2. Прогон бота

Скил `bot-run`: каждый готовый уровень должен проходиться ботом, без ошибок в консоли.

## 3. Глазами на телефоне

Скил `test-link` — обновить тестовую ссылку. Пройти в браузере с размером 375×812 (`resize_window`,
`preset: "mobile"`) и лёжа 812×375, на обоих языках (кнопки RU/EN в меню):
меню, карта, брифинг, игра, выбор улучшения, пауза, итоги (победа и гибель), «Ангар».
Ищи: текст вылезает за край или ложится на другой, непереведённые надписи, рамки выбора на телефоне.

## 4. Что остаётся автору

Отметь в `docs/yandex-release.md` сделанное. Загрузка архива `build/gorky-67-yandex.zip` в Консоль,
проверка в режиме отладки, возрастной рейтинг и `npm run deploy` — только автор (у него аккаунты).
