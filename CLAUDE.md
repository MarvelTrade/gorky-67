# GORKY-67 — прототип

## Что делаем
Браузерная 2D-игра в жанре survivors-like (как Vampire Survivors / DRG: Survivor), вид сверху.
Игрок — экспериментальный вертолёт «Изделие 67» над выдуманным закрытым городом (см. «Сеттинг»).
**Управление одним пальцем:** игрок только двигает вертолёт, стрельба автоматическая.
Цель прототипа — проверить, хочется ли сыграть второй забег. Не делать «полную игру».

## Сеттинг
- «Горький-67» (на экране — GORKY-67): выдуманный закрытый советский город, 1983 год.
- Авария на «Объекте 67», препарат «Заря» превращает людей в заражённых. Приказ «Купол» — никого не выпускать.
- Игрок — пилот «Сокол», прикрывает эвакуационную колонну. Диспетчер — «Берёза». Тон — экшен, не хоррор.
- Сюжет подаётся только короткими строками: телеграмма перед забегом, одна реплика «Берёзы» на волну, две концовки.
- Враги: заражённые, заражённый вездеход, зенитная установка оцепления, танк оцепления, босс «Объект» (мутант).
- **Никаких реальных марок и моделей техники** (УАЗ, «Шилка», Т-72 и т.п.), реальных событий и брендов. «Горький-67» — выдуманный город, оставляем.
- Все тексты — в `src/i18n/ru.js` и `src/i18n/en.js` с одинаковыми ключами.

## Стек
- Phaser 4 (последняя стабильная 4.x), JavaScript (без TypeScript на этапе прототипа)
- Vite — сборка и dev-сервер
- Платформа: Яндекс Игры (позже). На этапе прототипа SDK НЕ подключаем, но архитектура должна это позволять (см. «Подготовка к Яндекс Играм»).
- Графика на старте — примитивы Phaser (треугольники, круги, прямоугольники). Никаких чужих спрайтов. Позже — только ассеты с лицензией CC0 (например, Kenney) или свои.
- Разработка на MacBook Air M1 8 ГБ: никаких тяжёлых зависимостей.

## Управление
- Мобильный: палец на экране = точка, к которой плавно летит вертолёт (или виртуальный джойстик там, где коснулся). Отпустил — вертолёт зависает.
- Десктоп: WASD/стрелки + мышь как альтернатива.
- Вертолёт поворачивается носом в сторону движения, с лёгкой инерцией.
- Отключить контекстное меню и выделение по долгому нажатию в игровой области.

## Геймплей прототипа (scope v0.1 — строго это, не больше)
1. Забег длится 5 минут. Цель — выжить.
2. Вертолёт имеет HP. Касание врага / снаряда — урон.
3. Оружие стартовое: пулемёт, автоматически стреляет в ближайшую цель.
4. Враги (3 типа):
   - Пехота — медленная, много, идёт на игрока.
   - Джип — быстрее, мало HP, рывками.
   - Зенитка — стоит на месте, стреляет медленными снарядами.
5. Волны усиливаются со временем (каждые 60 с — больше врагов / новый тип).
6. Убитые враги роняют кристаллы опыта; вертолёт подбирает их магнитом.
7. Новый уровень → пауза → выбор 1 из 3 улучшений:
   - урон пулемёта, скорострельность, скорость полёта, радиус магнита, HP, +1 ракета (самонаводящаяся, раз в N секунд).
8. В начале 5-й минуты (4:00) — мини-босс «Объект»; убил — досрочная победа.
9. Экран итогов: время, убито, уровень, кнопка «Ещё раз».

## Сцены
- `BootScene` — загрузка
- `MenuScene` — название, кнопка «Играть»
- `GameScene` — геймплей
- `UIScene` — HUD поверх игры (HP, полоска опыта, таймер)
- `LevelUpScene` — выбор улучшения (пауза)
- `GameOverScene` — итоги

## Структура
```
/src
  main.js            — конфиг Phaser
  /scenes            — сцены
  /entities          — Player, Enemy, Projectile, XPGem
  /systems           — WaveSpawner, Upgrades, AutoAim
  /platform          — platform.js (обёртка над SDK, сейчас — заглушки)
  config.js          — ВСЕ балансные числа в одном месте
/public              — ассеты
index.html
```

## Правила кода
- Все числа баланса (скорости, HP, урон, частота волн) — только в `config.js`.
- Враги и снаряды — через пулы объектов (Phaser Groups), без создания/удаления в каждом кадре. Цель — стабильные 60 FPS на среднем телефоне при 200+ врагах.
- Физика — Arcade Physics.
- Без внешних CDN в рантайме: всё собирается в `dist/`.
- После каждой фичи — запуск `npm run build` и проверка консоли браузера на ошибки.
- Делать по одному шагу, коммитить в git после каждого рабочего шага.

## Яндекс Игры (ветка yandex-sdk)
- `npm run build:yandex` → `build/gorky-67-yandex.zip` (index.html в корне, проверка имён и размера). Только эта сборка
  подключает SDK (`.env.yandex`: `VITE_PLATFORM=yandex`); `npm run dev`, `npm run build` и `npm run deploy` — на заглушках.
- SDK грузится динамически из `/sdk.js` (относительный путь — для архива из Консоли). Нет SDK — заглушки, без падений.
- `platform.gameReady()` — один раз, когда на экране меню. `gameplayStart/Stop` — забег, выбор улучшения, смерть.
- Пауза от платформы (`game_api_pause/resume`) и реклама: забег на паузу, звук выключен.
- Реклама: межстраничная при «Ещё раз», не чаще `ADS.fullscreenMinInterval`; «Воскреснуть» за rewarded — раз за забег.
- Сохранения (рекорд, настройки звука) — `player.setData/getData`, копия в localStorage.
- В сборке для Яндекса нет кнопки «Скопировать статистику» и бота.

### Изначальный план подготовки
- `platform.init()`, `platform.gameReady()` (вызвать, когда игра реально готова к игре), `platform.gameplayStart/Stop()`
- `platform.showFullscreenAd()` — между забегами, не чаще разумного
- `platform.showRewardedAd()` — «Воскреснуть» после смерти (1 раз за забег)
- `platform.saveProgress()/loadProgress()` — рекорд и настройки
- `platform.getLang()` — язык интерфейса (ru/en), тексты в отдельном словаре
- Звук обязательно на паузу: при показе рекламы и при уходе со вкладки (visibilitychange)
- Билд: `dist/` с `index.html` в корне архива

## Порядок работы
1. Каркас: Vite + Phaser, пустая GameScene, вертолёт летит за пальцем/мышью.
2. Пулемёт с автонаведением + пехота.
3. Опыт, уровни, экран выбора улучшений.
4. Джип, зенитка, волны по таймеру.
5. HUD, Game Over, рестарт.
6. Босс на 5-й минуте.
7. Проверка на телефоне через локальную сеть (`vite --host`).
8. Сюжет и сеттинг: тексты, телеграмма, радио «Берёзы», перекраска, танк, концовки.
9. «Сочность» и замеры: частицы, цифры урона, звуки, статистика забегов, баланс по замерам ботом.

## Выкладка и замеры
- Код — приватный репозиторий `MarvelTrade/gorky-67`. Игра для тестеров — публичный `MarvelTrade/gorky-67-play`
  (только содержимое `dist/`, без исходников), GitHub Pages: https://marveltrade.github.io/gorky-67-play/
- Обновить игру по ссылке: закоммитить изменения и `npm run deploy` (`npm run deploy -- --dry` — без пуша).
- Тестеры жмут «Скопировать статистику» на экране итогов: причины смерти, улучшения по порядку, босс, забеги подряд.
- Бот для замеров баланса — `src/dev/bot.js`, только в dev-сборке. В консоли браузера: `__startBot({ smart: true })`,
  `__startBot()` (случайные улучшения), `__startBot({ dodge: false })` (новичок); итог — `__bot.log`.
  Вкладка должна быть видна: в фоне браузер тормозит игру и замеры врут.
- Меняя баланс, оставлять в `config.js` комментарий, какой замер к этому привёл.

## Чего НЕ делать в v0.1
Магазин, мета-прогрессия, несколько персонажей, карта мира, сюжет длиннее одной строки, реклама, мультиплеер, свои 3D-модели.

## Критерий успеха прототипа
5–10 человек играют без объяснений, и большинство САМИ нажимают «Ещё раз».
