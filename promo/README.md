# Промо для черновика Яндекс Игр

| Поле черновика | Файлы | Требования |
|---|---|---|
| Иконка (обяз.) | `icon-a.png`, `icon-b.png`, `icon-c.png` | 512×512 PNG |
| Обложка (обяз.) | `cover-a.png`, `cover-b.png`, `cover-c.png` | 800×470 PNG |
| Скриншоты — десктоп (обяз., ≥2) | `shot-desktop-1..3.jpg` | 16:9, 1280–2560 px, JPEG |
| Скриншоты — мобильные (обяз., ≥2) | `shot-mobile-1..3.jpg` | 9:16 портрет, 1280–2560 px, JPEG |
| Горизонтальное видео (обяз.) | — пока нет | 16:9 MP4, до 28 с, высота от 400 px |

## A/B-тест иконок и обложек

Яндекс сравнивает **два** варианта — контрольный и экспериментальный, иконка и обложка идут парой.
Тест запускается после публикации, длится от 7 до 14 дней. Поэтому три варианта — это два теста подряд:

1. Публикация с парой **C** (иконка «67» + обложка с ящиком) — контроль.
2. Тест 1: эксперимент — пара **A** (прорыв из орды). Самые непохожие варианты — быстрее виден эффект.
3. Тест 2: победитель теста 1 против пары **B** («Объект»).

Смотреть не только на CTR, но и на продуктовые метрики (время в игре, повторные забеги):
яркая картинка может давать клики, но не игроков.

## Как перерисовать

Иконки и обложки: `npx vite --port 5177`, открыть `http://localhost:5177/promo.html`, композиции — в `src/promo/main.js`.
Скриншоты сняты из настоящей игры ботом в ускоренном режиме (орда 1:30, вторая фаза «Объекта», ящик снабжения),
FPS-счётчик скрыт, урон по вертолёту на время съёмки выключен.
